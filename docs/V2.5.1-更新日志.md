| 项目 | 实现 |
|---|---|
| 灯光 / 材质 / 对比度 | 克隆原方向光生成冷色补光（不依赖模块内部的 THREE 构造器）；材质 roughness×0.88、metalness×0.8；`toneMappingExposure` 由 1.15 提升到 1.25 |
| 模型比例与取景 | 不缩放几何体；遍历 `geometry.boundingBox` 与 `matrixWorld` 计算真实包围球，取「原默认视角 + 包围球取景」中值作为新初始视角，保证内容不被裁切 |
| 关键元件 / 信号状态 | 每场景新增教学信息面板：3 个关键元件名称 + 信号状态描述 + 说明；统一 0 / 1 / X 三值图例；底部实时显示对象数、包围半径、相机 r、安全区间、渲染状态 |
| 相机防穿模 | `limits.min = max(原下限, 包围半径×0.95)`，相机不能进入模型内部；状态栏明确标注「视角安全 / ⚠ 可能穿模」 |
| 平滑过渡 | 沿用原模块 sph→tar 插值，并新增 `smoothTo(id,target,ms)` 三次缓动（可取消、pagehide 释放）；控制条与信息面板有 CSS 过渡 |
| 生命周期 | `suspend()` 暂时隐藏只停 RAF、保留 GPU 资源；`release()` 永久释放 geometry/material/texture、`renderer.dispose()` + `forceContextLoss()`、移除 window/宿主监听、注销注册表、用干净快照重建区段；`recreate()` 重新执行原始内联 module 源码并重新注册 |
| 监听器防泄漏 | 生命周期模块记录每场景的两个 WebGL 上下文监听与尺寸观察目标，释放时逐个 `removeEventListener` / `unobserve`；全站仅 1 个 `ResizeObserver` |

**逐场景验收**：每个场景都执行了交互（重置/环绕/缩放）、真实渲染截图、反复进出，以及「永久释放 → 重建」；五个场景全部通过，前后截图见 `docs/V2.5.1-界面对比.md`。

## 二、阶段 2 · 电路编辑器交互优化

| 项目 | 实现 |
|---|---|
| 移动端直接触摸拖放 | 元件库按钮 `pointerdown`（非鼠标）生成跟随手指的「幽灵元件」，松手落在画布即按网格放置；鼠标仍用 HTML5 `dragstart/drop`，另保留「先点元件再点画布」 |
| 端口事件委托 | SVG 端口/开关/导线/节点改为 `data-role` + 画布级 `click`/`keydown` 统一分发，重绘不再重复注册监听器；测试验证 10 次重绘后端口仍只响应一次 |
| 手势冲突 | 单一 `gesture` 状态机（idle / node / pan / wire / pinch / touchdrop）；进行中拒绝新手势，双指按下自动升级为 `pinch` 并取消未完成连线；缩放围绕双指中点 |
| 吸附与错误提示 | 连线预览时 28 单位内自动高亮最近输入端口并显示 `✓ 吸附到 nX 的 X 输入端`；预校验自连接、source/sink 方向、CLK 接非 CLOCK 等，给出中文原因 + 画布红色边框 + 状态栏说明 |
| 撤销重做一致性 | 每次撤销/重做后调用 `M.validate()`；新增 `historyStatus()` 同时校验当前电路与两条栈内全部快照；`M.validate` 失败即报错 |
| 旧 JSON 兼容 | V1.6 `version:1` 存档（含 tick=3、3 条时钟历史）导入后被引擎校验通过，tick 与历史完整保留 |
| 桌面不回退 | 新增独立测试验证 `dragTo` 鼠标拖放与鼠标端口点击仍然可用 |

## 三、阶段 3 · 波形分段归档

新增 `assets/labs/waveform-analyzer/v2.5.1-wave-archive.js`（纯数据模块），波形仪改为使用归档：

- 保留 0 / 1 / X 三值，采样仍由 `DigitalV25Signals.sample()` 直接读取 `M.evaluate()`，不重算逻辑。
- **分段归档**：每段 256 采样、最多 8 段（2048 条），另有 2 MB 估算字节上限；超限按整段 FIFO 丢弃并记录 `dropped`/`firstIndex`。
- 保留放大/缩小、水平滚动、时间游标点击定位、↑ 有效沿标记、单步/自动/暂停/复位/清除/手动采样。
- 新增「⇩ 导出波形 / ⇧ 导入波形」：导出带 `version:2` + `kind` + `source` 标记，导入对版本、分段数、每条采样的 tick/edge/channels 和 0/1/X 值逐项校验；非法文件给出中文失败原因且不破坏现有归档。
- 波形历史**只存在会话内**，`localStorage` 仅保存通道与缩放配置，避免浏览器长期运行后存档膨胀。
- 界面明确标注上限、当前条数、估算内存与已丢弃条数；继续声明「理想离散事件教学数据，不能当作真实示波器测量结果」。

**过程中真实出现并修复的失败**
1. `doc is not defined`：编辑器补丁误用了 `document` 的别名 → 统一为 `document`。

3. 触摸测试混入不可跨上下文传递的函数字符串 → 改为页面内直接构造 `PointerEvent`，并拆成严格的触摸/桌面两条独立测试。
4. 归档统计 `total` 被写成累计写入数、`importData` 引用已删除变量 → 改为按段维护 `held`。
5. 统计行复用 `.v25-wave-readout` 类导致原有断言匹配两个元素 → 改用独立类名。
6. 结构自检引用了尚未初始化的 `wave` 变量、模型边界文案断言写错 → 按实际代码修正，不虚报实现。
7. 场景释放/重建后 `contextHandlers` 计数不平衡、非活动场景未暂停 → 见阶段 4 修复。
8. CDN 注册偶发较慢导致后续用例被跳过 → `ready()` 增加 15 秒 `waitForFunction` 等待注册。

## 八、已知问题与未完成

1. C2 的「增加关键元件名称」以 HTML 教学信息面板（含 0/1/X 图例与信号说明）实现，未在 Three.js 场景内生成 3D 文字标签或 Sprite；标签不随模型旋转而移动。
2. 防穿模采用包围球半径下限约束，未做逐三角面片的视线遮挡检测；复杂模型仍可能有局部遮挡。
3. `release/recreate` 通过重新执行原始内联 module 源码实现，会重新向 `window` 注册 resize 监听；本模块在每次释放时移除上一轮重建新增的监听，但首次加载时的 6 个原监听会保留（不重复增长）。
4. 端口点击已改为画布级委托，但节点组仍保留 `data-role` 标记；`drawNodes()` 每次重绘会重建 SVG 子元素，未做虚拟 DOM 复用（元素总数受元件上限 80 约束）。
5. 波形归档上限固定为 2048 条 / 2 MB 估算，超出后最旧数据不可恢复；如需长期保存请使用「导出波形」。
6. 波形与电路仍为理想离散事件教学仿真，不计算传播延迟、噪声、建立保持时间违例或亚稳态；不是真实示波器测量。
7. Actions 日志下载仍返回 `403`（需仓库管理员权限），无法读取 CI 逐项明细，以步骤结论 + 本地等价复现为准。
