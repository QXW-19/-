# V2.5.1 教学内容建设说明

> 目标：把「有页面」变成「有内容」。在不改动既有 51 个教学模块、32 节讲义原始数据、
> 旧存档结构和任何已验证公式的前提下，为每节补四块深读内容，为每章补实用案例库，
> 并让每个案例都能回到互动实验里验证。

## 一、数据契约（唯一事实来源）

`assets/content/v2.5.1-content-core.js` 定义三类数据及其校验规则，注册时缺字段直接抛错，
避免出现「空白案例页」或「占位文字」上线。

| 类型 | 固定结构 |
| --- | --- |
| 讲义深读 `C.lesson(id,data)` | `beginner` 零基础引入、`principle` 深入原理、`example{question,steps[],answer,check}` 分步计算例题、`mistakes[≥3]{wrong,why,fix}` 常见错误解析 |
| 实用案例 `C.case(data)` | 十三个部分：`bg`、`concepts`、`spec`、`block`、`table`、`logic`、`parts`、`steps`、`lab`、`tests`、`trouble`、`extend`、`summary` |
| 综合项目 `C.project(data)` | 八个部分：`bg`、`spec`、`block`、`plan`、`detail`、`integration`、`test`、`review` |

运行期校验要求：案例真值表至少 2 行、测试用例至少 2 条、故障排查至少 2 条；
讲义例题至少 3 步、错误解析至少 3 条且每条三段齐全。

## 二、呈现方式

- **讲义页**：四块深读以 `<details>` 折叠面板插入「第一部分」「第二部分」内部，
  不新增 `.v18-panel`，因此 V2.4.1 的七段学习路径、预测面板、知识总结断言全部不受影响。
  首块「零基础引入」默认展开，并提供「全部展开 / 全部收起」。
- **案例库**：独立模块 `#v251-cases`，支持按章筛选与关键词搜索；详情按十三部分顺序渲染，
  含真值表、表达式、器件表、分步搭建、测试用例、故障排查与自评量规。
- **互动**：案例内可直接打开电路实验室（`DigitalV25Lab.loadCircuit`）、章节互动模块（`window.show`），
  案例 1-1 另附与真值表同源的七段数码管小实验。
- **窄屏**：表格统一包在 `overflow-x:auto` 容器内，375 px 下页面无横向溢出。

## 四、内容准确性做法

1. **七段段码**：以 `a b c d e f g` 顺序、共阴 1=亮独立定义 0~9 的段集合，
   由脚本逐行复算段码与十六进制值（`0x7E, 0x30, 0x6D, 0x79, 0x33, 0x5B, 0x5F, 0x70, 0x7F, 0x7B`）。
2. **段表达式**：`a = B3 + B1 + (B2 ⊙ B0)`、`b = /B2 + (B1 ⊙ B0)` 对 0~9 逐码回代验证；
   1010~1111 作为无关项处理，并在案例中明确「无关项不等于一定熄灭」。
3. **格雷码**：`G = B ⊕ (B>>1)` 逐行复算，并验证 16 个码首尾相邻汉明距离恒为 1。
4. **补码**：逐位模拟全加器，独立算出 `Cp`、`Cs`、`OV = Cp ⊕ Cs` 与十进制读数，
   与案例算例表逐行比对；特别收录 `−1+1`（有进位但不溢出）与 `5+3`（和看似合法却溢出）两个反例。
5. **来源**：只参考阎石《数字电子技术基础》第六版的知识顺序，全部解说为原创；
   自动化测试禁止出现「第 N 页」「教材原文」等表述，也不虚构器件参数（一律提示查数据手册）。
