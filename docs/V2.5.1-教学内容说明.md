# V2.5.1 教学内容建设说明

> 目标：把「有页面」变成「有内容」。在不改动既有 51 个教学模块、32 节讲义原始数据、
> 旧存档结构和任何已验证公式的前提下，为每节补四块深读内容，为每章补实用案例，
> 另加四个综合项目，并让案例都能回到互动模块里验证。

## 一、数据契约（唯一事实来源）

`assets/content/v2.5.1-content-core.js` 定义三类数据与校验规则，注册时缺字段直接抛错，
避免「空白案例页」或占位文字上线。

| 类型 | 固定结构 |
| --- | --- |
| 讲义深读 `C.lesson(id,data)` | `beginner` 零基础引入、`principle` 深入原理、`example{question,steps[],answer,check}` 分步计算例题、`mistakes[≥3]{wrong,why,fix}` 常见错误解析 |
| 实用案例 `C.case(data)` | 十三部分：`bg`、`concepts`、`spec`、`block`、`table`、`logic`、`parts`、`steps`、`lab`、`tests`、`trouble`、`extend`、`summary` |
| 综合项目 `C.project(data)` | 八部分：`bg`、`spec`、`block`、`plan`、`detail`、`integration`、`test`、`review` |

运行期校验：案例真值表 ≥2 行、测试用例 ≥2 条、故障排查 ≥2 条；
讲义例题 ≥3 步、错误解析 ≥3 条且每条三段齐全。

## 二、呈现方式

- **讲义页**：四块深读以 `<details>` 折叠面板插入「第一部分」「第二部分」内部，
  不新增 `.v18-panel`，因此 V2.4.1 的七段学习路径、预测面板、知识总结断言全部不受影响。
  首块「零基础引入」默认展开，并提供「全部展开 / 全部收起」。
- **案例库** `#v251-cases`：按章筛选、关键词搜索；详情按十三部分渲染，
  含真值表、表达式、器件表、分步搭建、测试用例、故障排查与自评量规。
- **综合项目** `#v251-projects`：四个项目卡片 + 八部分详情（指标、计划、联调、测试记录、量规）。
- **互动**：案例内可打开电路实验室（`DigitalV25Lab.loadCircuit`）或章节互动模块（`window.show`）；
  案例 1-1 另附与真值表同源的七段数码管小实验。
- **窄屏**：表格统一包在 `overflow-x:auto` 容器内，375 px 下无横向溢出；详情页会隐藏卡片列表。

## 四、内容准确性做法

1. **七段段码**：独立定义 a~g 段集合，逐行复算段码与十六进制值（7E/30/6D/79/33/5B/5F/70/7F/7B）。
2. **段表达式**：`a=B3+B1+(B2⊙B0)`、`b=/B2+(B1⊙B0)` 对 0~9 逐码回代；无关项明确说明「不等于一定熄灭」。
3. **格雷码**：`G=B⊕(B>>1)` 逐行复算，并验证 16 码首尾相邻汉明距离恒为 1。
4. **补码**：逐位模拟全加器算 `Cp`、`Cs`、`OV=Cp⊕Cs`，收录 `−1+1`（有进位不溢出）与 `5+3`（和合法却溢出）反例。
5. **多数表决 / 与非异或 / 无关项化简**：真值表逐行、N1~N3 中间节点逐组、`F=B3+B2(B1+B0)` 逐码复算。
6. **555 / ADC / DAC**：`T=0.693(R1+2R2)C`、`Δ=Vref/2ⁿ`、`Vout=Vref·D/2ⁿ` 全部用独立脚本计算，表格数值与公式一致。
7. **来源与参数**：只参考阎石第六版的知识顺序，解说全部原创；测试禁止出现「第 N 页」「教材原文」；
   所有真实器件参数一律写「查数据手册」，教学假设值均标注为假设。

## 六、扩展方式

新增一章内容只需两步：在 `assets/content/lessons/` 与 `assets/content/cases/` 放 `chNN.js`，
再在主页按顺序加两个 `<script defer>`。`test:content` 会自动发现新章节并校验四节齐全、
案例不少于 2 个；`verify-v2.4-split.cjs` 的脚本总数断言需同步更新（当前 103）。
