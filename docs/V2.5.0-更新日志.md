## 一、各阶段实现内容

### 阶段 A · 可视化数字电路实验室 2.0
- 分类元件库（输入 / 时钟 / 组合逻辑 / 时序逻辑 / 输出，13 种元件）；鼠标拖放 + 触屏「先点元件再点画布」放置；20px 网格对齐。
- SVG 画布：滚轮缩放、拖拽平移、连接预览虚线、端口吸附；选中、复制、删除、撤销 / 重做（Ctrl+Z / Ctrl+Y / Ctrl+Shift+Z / Delete / Esc）。
- 点击输出端口→输入端口接线；点击已连接输入端或导线断线；重连自动替换旧线并给出说明；非法连线由引擎 `M.validate()` 拒绝并翻译为中文错误。
- **三值逻辑可视化直接读取 `M.evaluate()`**：逻辑 1 高亮实线、逻辑 0 低亮实线、未知 X 虚线 + 「X」标签、非法连接红虚线 + 中文原因；时钟上升沿有 500ms 高亮提示（由 `M.pulse()` 事件驱动，不是装饰性电流动画）。
- 七类中文诊断：输入悬空、重复接线、组合反馈环、时钟端接线不合理、连接类型错误、仿真含 X、元件/导线超限；分「错误 / 警告 / 教学提示」三级。
- 存储使用独立带版本键 `digital-course-v2.5-circuit`（`version:2`），内部电路仍是 V1.6 `version:1` 结构；导出为 V1.6 原始 JSON，旧实验室可直接导入；只读兼容旧键 `digital-course-v1.6-mixed`。

### 阶段 B · 交互式时序波形分析仪
- 多通道（CLOCK、输入开关、门与触发器/计数器输出）可选；0/1/X 三值数字阶梯波；放大 / 缩小 / 水平滚动；时间游标点击定位；↑ 有效上升沿标记；单步时钟、自动时钟、暂停、复位、清除历史、手动采样当前状态。
- **仿真数据同步**：波形记录来自 `DigitalV25Signals.sample()`，该函数只读取 `M.evaluate()` 的结果，不重新实现任何逻辑运算。已核对 V1.6 `M.pulse()` 的离散事件顺序：CLOCK 拉高 → `applyEdge()` 内组合逻辑求值 + 上升沿识别 + 全部寄存器同时更新 → CLOCK 拉低 → 再次求值 → `tick++` → 记录历史，与要求一致，因此直接复用而不另建事件模型。
- 六个可直接加载的教学案例：半加器、D 触发器边沿采样、T 触发器翻转、JK 触发器状态变化、模 6 计数器、简单状态机；每个含理论目标、操作步骤、预期结果、验证说明。
- **精度边界已明确声明**：理想数字逻辑与离散事件教学仿真，不计算真实传播延迟、噪声、建立/保持时间违例或亚稳态；波形是离散采样记录，不是真实示波器测量结果。

### 阶段 C · 五个 3D 场景深度升级
- 向 w1～w5 五个既有 Three.js 模块注入统一注册接口（各模块作用域内仅增加一次 `register()` 调用，未改写教学模型）。
- 新增：一键重置视角、自动环绕 / 停止、暂停 / 恢复渲染、缩放按钮带半径边界、单指拖拽旋转 + **双指触摸缩放**（`touch-action:none`）、实时球坐标状态显示。
- 生命周期：离开场景把原模块 `running` 置 false 以停止 RAF；重新进入由原 `onShow_wN` 恢复；全站**单个** `ResizeObserver`；`webglcontextlost/restored` 中文降级与循环暂停/恢复；CDN/WebGL 不可用时显示降级说明；`pagehide` 释放观察者、定时器与自动环绕。
- 分级验收覆盖：① 页面入口 ② WebGL 上下文初始化 ③ 真实 3D 对象（scene.children 13–34 个）+ 截图 ④ 相机交互实际改变 `tar.r/th` ⑤ 反复进出 3 轮资源正常暂停/恢复且监听器不重复注册。

### 阶段 D · 课程与实验联动
- 逻辑门、半加器、触发器、计数器、时序逻辑、状态机相关 17 节讲义，在「先预测实验结果」面板提供一键打开对应案例按钮，直接载入电路 + 波形，形成「理论精讲 → 预测 → 打开实验 → 改参数 → 观察波形 → 理解原因 → 随堂检测」闭环。
- 旧版学习记录键与数据结构零改动；新增实验配置独立带版本号，导入时对 V1.6 原始 JSON、V2.5 包装格式都做 `M.validate()` 校验，非法版本明确拒绝。

### 阶段 E · 工程结构与性能
- 新增目录 `assets/labs/{circuit-editor,circuit-renderer,waveform-analyzer,examples}`、`assets/scenes/{controls,lifecycle}`、`assets/styles/v2.5-lab.css`、`tests/unit/`。
- 画布级指针/点击统一委托；波形输出未变化时跳过 DOM 写入；`pagehide`/`visibilitychange` 释放自动时钟、边沿动画定时器、观察者。
- 主 HTML 309,568 字符，19 个内联脚本 / 82 个 script 标签；51 个原始模块、八章、32 节讲义、五个 3D 场景、考试系统、学习记录全部保留。

### 阶段 F · 自动化测试与交付

## 八、Windows + VSCode 启动与测试命令

在 PowerShell（仓库根目录 `v24-dev`）执行：

```powershell
# 1. 拉取并切换到 V2.5 分支
git fetch origin feature/digital-course-v2.5
git checkout feature/digital-course-v2.5

# 2. 安装依赖与 Chromium（首次或换机后）
npm ci --no-audit --no-fund
npx playwright install chromium

# 3. 启动本地静态服务（外部脚本/模块需要 HTTP，不要直接双击 file://）
py -m http.server 8001 --bind 127.0.0.1
# 浏览器打开 http://127.0.0.1:8001/

# 4. 全量回归（含静态、单元与浏览器）
npm run test:all

# 5. 只跑某一类
npm run test:unit        # V2.5 电路仿真单元测试（12 项）
npm run test:v25         # V2.5 工程结构自检（51 项）
npm run test:browser     # 全部 Playwright 浏览器测试（88 项）
npx playwright test tests/browser/v25-lab.spec.cjs        # 仅电路实验室
npx playwright test tests/browser/v25-scenes.spec.cjs     # 仅 3D 分级验收

# 6. 本地反复回归时避免历史报告堆积（CI 不需要）
$env:PW_OUTPUT_DIR = "F:/数字电路交互网页/_work_v24/pw-local"
npm run test:all
```

> 注意：Playwright 会自行启动 `tests/static-server.cjs`（端口 8001）。若手工启动了 Python 服务，请先停止，或设置 `reuseExistingServer`；本地运行时 `CI` 环境变量不要设为 `1`（CI=1 时禁止复用已存在服务）。
