## 三、统一能力与限制

- 四个项目都有「任务介绍 / 原理 / 设计 / 分步搭建 / 实时仿真 / 波形 / 排查 / 总结」八步，进度独立保存。
- 仿真页均提供「计算规则」与「实时结果」并排对照，结果来自引擎/模型即时计算。
- 无法用现有元件准确复现的部分（如三态高阻、模拟电平、555 模拟 RC）不做假动画，
  在案例联动卡中标注为「仅数值计算或图形演示」。
