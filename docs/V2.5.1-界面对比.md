# V2.5.1 界面改进前后对比

截图由 Playwright + Chromium 真实渲染采集，视口 1440×900（手机 390×844）。「改版前」为 `feature/digital-course-v2.5` @ `da90df9`，「改版后」为 V2.5.1。
