# 数字电子技术基础 · 互动课堂

## V1.1.0 增量升级

原有数字电子技术课程、19 个互动模块、章节习题、教师讲义与 5 个 3D 场景保持不变。本版本新增：

- 手动章节完成标记、学习进度条与继续学习
- 每章 2 题的基础选择题（总计 16 题），自动判分与解析
- 错题本与 localStorage 学习记录
- 学习记录导入/导出及清空
- 深色模式和字体调整

新增代码独立存放在 `assets/v1.1.js` 和 `assets/v1.1.css`，没有对原课程公式进行改写。

## Windows VSCode 运行

下载仓库并使用 VSCode 打开，推荐安装 Live Server 插件，右键原 HTML 文件选择 Open with Live Server。

也可以在项目根目录使用 PowerShell：

```powershell
py -m http.server 8000
```

浏览器访问 http://localhost:8000/ 并点击 `数字电子技术基础-互动课堂.html`。

Three.js 仍由原页面通过 CDN 加载，断网或 WebGL 不可用时 3D 效果可能降级。

## 手动验收清单

1. 每章课程均可以打开且原互动控件能使用。

## V1.3.0 虚拟数字电路实验室（基础版）

本阶段从 `feature/digital-course-v1.2` 创建新分支，保留八章精讲、原有 51 个模块、V1.1 学习记录和 V1.2 增补教材。

### 新增功能

- 左侧导航增加「扩展实验 · V1.3 / 虚拟数字电路实验室」。
- 八类组件：**输入开关、与门、或门、非门、异或门、与非门、或非门、LED**。
- 点击元件库按钮或拖入画布添加元件；拖动元件标题改变位置。
- 从元件右侧输出圆点点击，再点击另一个元件左侧输入圆点建立连接；点击已连接输入或连线可断开。
- 输入开关在 0/1 间切换，实时更新所有逻辑门输出和 LED 状态。
- 自带「与门」「半加器」两组预置电路，展示 AND 和 SUM/CARRY 两个输出。
- 自动生成最多四个开关、16 行的真值表；未接线输入为 X（未知）。
- 浏览器本地保存实验电路，支持 JSON 导入、导出与清空。
- 拒绝非法端口、一个输入重复接线和组合逻辑反馈环，导入时限制最多 80 个元件和 160 根导线。

### 使用方法（Windows VSCode）

在仓库根目录运行：

```powershell
node .\tests\verify-v1.2.cjs
node .\tests\verify-v1.3.cjs
py -m http.server 8001 --bind 127.0.0.1
```

在 Edge/Chrome 中打开 `http://127.0.0.1:8001/`，进入 `数字电子技术基础-互动课堂.html`，然后在左边导航底部进入「虚拟数字电路实验室」。

### 使用步骤

1. 点击「载入与门示例」，按顺序将两个开关都切换到 1，LED 应点亮。
2. 点击「载入半加器」，先对照真值表，再切换开关验证 SUM（XOR）与 CARRY（AND）。
3. 点击元件库添加元件，拖动标题摆放位置，点击输出端和目标输入端进行连线。
4. 点击「导出电路 JSON」备份当前设计，再用「导入电路 JSON」恢复。
5. 刷新页面，确认本地保存状态是否恢复；检查原教学内容与 3D 场景是否仍正常运行。

### 测试状态与限制

- 未在真实教学网页里逐项完成浏览器验收。请按上面的步骤做 Windows 端验证。
- 当前是**理想无延迟组合逻辑教学仿真**，并不模拟真实电压、电流、传播延迟、触发器、复位、时钟或亚稳态，不适合充当真实芯片仿真器。

## V1.4.0 理想时序逻辑实验室（新增）

本版本基于 `feature/digital-course-v1.3` 创建独立分支，保留原有 **51 个静态教学模块**以及 V1.1/V1.2/V1.3 的学习、练习与组合逻辑功能。页面左侧新增 **扩展实验 · V1.4 → 时序逻辑实验室**。

### 四种实验模式

- **D 触发器**：在每次理想时钟上升沿令 Q⁺=D；沿之间保持。
- **T 触发器**：T=0 保持，T=1 在有效沿翻转，Q⁺=Q⊕T。
- **JK 触发器**：00 保持、01 清零、10 置位、11 翻转。
- **同步模 N 计数器**：N 可设为 2～16，每次上升沿加一，达到 N−1 后同步回到 0；位宽为 ceil(log₂N)。

### 界面与记录

- 自由切换输入 0/1，点击 **↑ 单步时钟** 或 **▶ 自动时钟**（500、1000、1500、2000 ms）。
- 显示当前寄存器 Q 的二进制状态、十进制计数、有效上升沿次数。
- 动态展示状态转移表、最近 12 个上升沿的**示意波形**、最近 48 条状态变化记录。
- **软件复位** 清零 Q、计数和历史；切换实验模式或计数模数时重置。
- 使用浏览器 localStorage 保存实验状态，可导入/导出 JSON；自动时钟切走页面或隐藏页面时暂停。

```powershell
node .\tests\verify-v1.4.cjs
py -m http.server 8001 --bind 127.0.0.1
```

浏览器访问 `http://127.0.0.1:8001/`，点击 `数字电子技术基础-互动课堂.html`，再在左侧下方打开「时序逻辑实验室」。可使用 `#v14-lab` 深链接访问。

### 课堂验收练习

1. D 模式把 D 设为 1，单步后 Q=1；再改 D=0，不按时钟时 Q 仍为 1；再单步变 0。
2. T 模式设置 T=1，连续单步观察 Q 的 1、0、1 交替变化；T=0 时状态保持。
3. JK 模式测试 J/K 的 00、01、10、11 四种组合。
4. COUNTER 模式设置 N=6，连续单步 6 次后应回到二进制 000；对照状态表检查。
5. 自动时钟运行后切换到其他章节，观察是否暂停；再返回确认历史保存。
6. 导出 JSON、刷新、导入，检查进度和时钟历史是否恢复。继续检查 V1.3 半加器及原有课程和 3D。

### 适用范围与局限

本版本是**独立的、基于离散理想上升沿的教学演示**。V1.3 的自由接线画布尚**不能与 V1.4 的触发器混合接线**，本版不实现真实芯片级仿真、时钟传播延迟、竞争冒险、建立/保持时间违例或亚稳态计算。波形图为采样事件示意，不代表真实连续时间电压波形。

V1.4 本地保存键为 `digital-course-v1.4-sequential`，与前面版本的记录相互独立，导出前请留意当前版本。静态回归测试覆盖 21 项核心行为，但不能替代浏览器交互及真实硬件测试。
