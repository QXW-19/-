## V1.4.0 理想时序逻辑实验室（新增）

本版本基于 `feature/digital-course-v1.3` 创建独立分支，保留原有 **51 个静态教学模块**以及 V1.1/V1.2/V1.3 的学习、练习与组合逻辑功能。页面左侧新增 **扩展实验 · V1.4 → 时序逻辑实验室**。

### 四种实验模式

- **D 触发器**：在每次理想时钟上升沿令 Q⁺=D；沿之间保持。
- **T 触发器**：T=0 保持，T=1 在有效沿翻转，Q⁺=Q⊕T。
- **JK 触发器**：00 保持、01 清零、10 置位、11 翻转。
- **同步模 N 计数器**：N 可设为 2～16，每次上升沿加一，达到 N−1 后同步回到 0；位宽为 ceil(log₂N)。

### 界面与记录

- 自由切换输入 0/1，点击 **↑ 单步时钟** 或 **▶ 自动时钟**（500、1000、1500、2000 ms）。
- 显示当前寄存器 Q 的二进制状态、十进制计数、有效上升沿次数。
- 动态展示状态转移表、最近 12 个上升沿的**示意波形**、最近 48 条状态变化记录。
- **软件复位** 清零 Q、计数和历史；切换实验模式或计数模数时重置。
- 使用浏览器 localStorage 保存实验状态，可导入/导出 JSON；自动时钟切走页面或隐藏页面时暂停。

### VSCode 本地运行与检查

```powershell

node .\tests\verify-v1.3.cjs
node .\tests\verify-v1.4.cjs
py -m http.server 8001 --bind 127.0.0.1
```

浏览器访问 `http://127.0.0.1:8001/`，点击 `数字电子技术基础-互动课堂.html`，再在左侧下方打开「时序逻辑实验室」。可使用 `#v14-lab` 深链接访问。

### 课堂验收练习

1. D 模式把 D 设为 1，单步后 Q=1；再改 D=0，不按时钟时 Q 仍为 1；再单步变 0。
2. T 模式设置 T=1，连续单步观察 Q 的 1、0、1 交替变化；T=0 时状态保持。
3. JK 模式测试 J/K 的 00、01、10、11 四种组合。
4. COUNTER 模式设置 N=6，连续单步 6 次后应回到二进制 000；对照状态表检查。
5. 自动时钟运行后切换到其他章节，观察是否暂停；再返回确认历史保存。
6. 导出 JSON、刷新、导入，检查进度和时钟历史是否恢复。继续检查 V1.3 半加器及原有课程和 3D。

### 适用范围与局限

本版本是**独立的、基于离散理想上升沿的教学演示**。V1.3 的自由接线画布尚**不能与 V1.4 的触发器混合接线**，本版不实现真实芯片级仿真、时钟传播延迟、竞争冒险、建立/保持时间违例或亚稳态计算。波形图为采样事件示意，不代表真实连续时间电压波形。

V1.4 本地保存键为 `digital-course-v1.4-sequential`，与前面版本的记录相互独立，导出前请留意当前版本。静态回归测试覆盖 21 项核心行为，但不能替代浏览器交互及真实硬件测试。

## V1.6.0 统一混合数字电路实验室

本分支从 `feature/digital-course-v1.5` 创建，完整保留八章原教材、原有 51 个静态教学模块、V1.1～V1.5 的增强内容及旧存档。新增独立页面 **「综合实验 · V1.6 → 混合电路搭建实验室」**。原 V1.3 组合逻辑画布和 V1.4 时序演示界面仍可单独使用；V1.6 是同一张画布上支持两类器件的升级版。

### 本次真正接通的功能

- 组合逻辑元件：开关、AND、OR、NOT、XOR、NAND、NOR、LED。
- 时序逻辑元件：D 触发器、T 触发器、JK 触发器，以及同步模 N（2～16）计数器。
- 增加 **CLOCK 时钟源**，支持单步脉冲和 500～2000 ms 自动脉冲。
- 从输出端连向器件输入端，支持多个输出口（计数器 Q0～Q3）；可移动/删除元件、断开导线，所有合法接线会实时计算。
- 组合逻辑输出可以接入触发器的 D/T/J/K 引脚；时钟源可以经组合门接入 CLK。寄存器输出再通过组合门反馈到自身输入的线路**允许**，不经过寄存器的组合逻辑环路**拒绝**。
- 同步计数器输入包含 CLK、EN（高有效使能）、RST（高有效同步复位）；它的 4 位输出可分别连接 LED。计数模数调整范围为 2～16。
- 逻辑采用 **0 / 1 / X（未知）** 三值计算：未接线输入为 X，已知控制输入仍可决定部分门的输出（例如 0 AND X=0）。
- 自动保存当前电路与最近 48 次时钟状态，支持 JSON 导入、导出。单个电路上限 80 元件、200 导线。
- 内置三套示例：**异或门→D 触发器→LED**、**模 6 计数器→四路 LED**、**JK 触发器翻转**。

### 技术说明与已知限制

- `assets/v1.6-core.js`：无依赖混合逻辑内核，按离散事件同步采样寄存器，并区分带寄存器的反馈与组合逻辑闭环。
- `assets/v1.6.js`：画布元件、连线、时钟、LED、历史记录、导入导出及本地保存。
- `assets/v1.6.css`：实验室专用响应式界面。
- `tests/verify-v1.6.cjs`：**32 项** Node.js 回归测试。

此版本是 **理想教学级数字仿真器**，并非电压/电流/功耗/时序物理仿真：不计算真实逻辑门传播延迟、脉宽、毛刺、时钟抖动、建立保持时间或亚稳态；所有 CLOCK 元件使用统一的逻辑脉冲控制。电路历史以脉冲后寄存器状态为单位，并非连续电压波形。局部接线之后的输入上升沿由模拟引擎检测；电路拓扑变化时会同步当前时钟值，防止把插线误当成时钟事件。

V1.6 的本地存档键为 `digital-course-v1.6-mixed`，与各旧版本存档独立。静态回归已完成，浏览器真实点击、移动端触摸和 3D 兼容性仍需在用户电脑上验收。

## V1.7.0 · 零基础导学 + 综合项目实训

**明确参考书：阎石《数字电子技术基础》第六版。** 目标是帮助没有电子基础的学习者循序渐进理解数字电子知识，并在浏览器中实际操作。新增内容是根据该书知识主线编写的原创通俗讲解、例题与项目，不是教材原文摘录。原有教材正文、章节与 V1.1～V1.6 的源码和数据均予以保留。

### 一、零基础入口（建议先从这里学）

左侧导航顶部新增 **「零基础课堂 · V1.7 → 从 0 开始学习（推荐）」**：

- 第一章：从开关的 0/1 理解二进制、位权、BCD。
- 第二章：用门禁例子理解与、或、非、逻辑函数。
- 第三章：从理想门到真实芯片的 CMOS、电平阈值和高阻态。
- 第四章：从 1 位加法引出半加器、译码器和多路选择器。
- 第五章：通过“拍照”类比理解触发器与时钟边沿。
- 第六章：用模 6 计数器理解有限状态机。
- 第七章：用周期、频率与占空比理解方波及 555。
- 第八章：用 8 位 ADC 认识量化和模拟/数字转换。

每章采用 **生活类比 → 三个入门术语 → 三步例题 → 可跳转的原教材和实验 → 一道检查理解的小题** 的结构。小题答对后自动记录章节入门进度，本地保存到 `digital-course-v1.7-beginner`。

> 这是一条用于帮助零基础者入门的导学路线，不是书中全部理论、习题或电气实践的替代品。

### 二、综合项目实训（学到组合及时序电路之后）

左侧导航底部新增 **「综合实训 · V1.7 → 数码管 / 交通灯 / 电子钟」**：

1. **4 位输入的七段数码管**：点击 D/C/B/A 四个开关或选择 0～F，观察实时段码；查看 16 行译码表。约定共阴极、逻辑 1 点亮，数字 8 的七段应全部亮起。
2. **交通灯有限状态机**：六个阶段：南北绿 10 s、黄 3 s、全红 2 s、东西绿 10 s、黄 3 s、全红 2 s；共 30 个模拟秒一循环。可单步、自动运行、查看状态表和历史记录。
3. **24 小时数字电子钟**：设置时、分、秒；推进一个模拟秒观察秒→分→时的级联进位，验证 23:59:59 下一秒为 00:00:00。

三项实验都有操作引导和**自动验收检查点**（数码管显示 8、交通灯完成整轮循环、电子钟跨越午夜）。进度存放在 `digital-course-v1.7-projects` 与 `digital-course-v1.7-checkpoints`，支持独立 JSON 导入导出和重置，不会覆盖旧版本进度。
