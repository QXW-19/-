# 数字电子技术基础 · 互动课堂

## V1.1.0 增量升级

原有数字电子技术课程、19 个互动模块、章节习题、教师讲义与 5 个 3D 场景保持不变。本版本新增：

- 手动章节完成标记、学习进度条与继续学习
- 每章 2 题的基础选择题（总计 16 题），自动判分与解析
- 错题本与 localStorage 学习记录
- 学习记录导入/导出及清空
- 深色模式和字体调整

新增代码独立存放在 `assets/v1.1.js` 和 `assets/v1.1.css`，没有对原课程公式进行改写。

## Windows VSCode 运行

下载仓库并使用 VSCode 打开，推荐安装 Live Server 插件，右键原 HTML 文件选择 Open with Live Server。

也可以在项目根目录使用 PowerShell：

```powershell
py -m http.server 8000
```

浏览器访问 http://localhost:8000/ 并点击 `数字电子技术基础-互动课堂.html`。

Three.js 仍由原页面通过 CDN 加载，断网或 WebGL 不可用时 3D 效果可能降级。

## 手动验收清单

1. 每章课程均可以打开且原互动控件能使用。
2. 每章末尾新增选择题可以作答，正确与错误会显示解析。
3. 错题本列出答错题目。
4. 章节完成状态刷新后保留，深色模式和字号刷新后保留。
5. 进度数据可以导出为 JSON、清空后重新导入。
6. 检查 5 个 3D 场景与浏览器 Console 是否正常。

本次属于第一阶段升级，尚未实现自动评分的全部原题、完整工程拆分、3D 离线打包以及端到端浏览器回归测试。

## V1.2.0 教材内容增强（独立开发分支）

此版本以 V1.1.0 为基础，**保留原有 51 个页面模块**，在八章精讲页面的章标题下方添加原创增强课程，采用“学习目标 → 重点精讲 → 分步例题 → 动手实验 → 知识检测”的结构。

- 八章共 **24 个知识精讲专题**：包括理想模型、适用前提和常见错误；
- **8 道分步例题**：按按钮逐步展示推导过程，支持重新推导；
- **8 项动手实验任务**：直接跳转到原有的对应互动模块；
- **16 道新增单选检测题**：提交后自动判分，解释原因，可重复作答；
- **V1.2 练习记录独立存储**：支持浏览器本地保存、在第一章导入和导出 JSON。

### 本地启动

在仓库根目录使用 VSCode Live Server 或运行：

```powershell
py -m http.server 8001 --bind 127.0.0.1
```

使用浏览器访问 `http://127.0.0.1:8001/` 并点击 `数字电子技术基础-互动课堂.html`。在任一章的“精讲”页面即可看到 V1.2 内容。

### 新增文件

- `assets/v1.2-content.js`：八章原创课程数据。
- `assets/v1.2.js`：课程渲染、例题步骤、检测评分、记录导入导出。
- `assets/v1.2.css`：响应式组件样式。

### V1.2 验收建议

1. 检查第一章至第八章是否均显示新增教学内容。
2. 点击“显示第 1 步”直到结束，再点击“重新推导”。
3. 完成一个新知识检测，刷新页面观察已选答案与解析是否保留。
4. 通过“打开对应互动实验”进入原有模块，检查其基本交互仍正常。
5. 从第一章导出 V1.2 检测记录，清除浏览器存储后再导入验证。
6. 检查 V1.1 进度与错题本、原有习题、五个 3D 场景及移动端布局。

**已知范围：** V1.2 检测记录使用独立 localStorage 键 `digital-course-v1.2`，V1.1 的 JSON 导出不包含 V1.2 检测记录。需要分别导出；本次并未引入后端或完整电路仿真器。新增内容是原创教学讲解，并非教材逐字复制；涉及硬件电气参数的实例仍应按器件手册验证。

### 无依赖的内容结构检查

在项目根目录运行：

```powershell
node tests/verify-v1.2.cjs
```

脚本检查八章资料、16 道题的选项与答案、8 个实验入口、原有 51 个模块、脚本语法及部分示例计算。此检查不替代浏览器交互验收。
